# Sahra — سهرة

واجهة تجريبية عربية RTL لمنصة أفلام ومسلسلات.

## الملفات
- `index.html` — بنية الصفحة.
- `styles.css` — التصميم المتجاوب.
- `app.js` — تفاعلات البطاقات والنافذة.

## تشغيلها على Vercel
1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub، وليس ملف ZIP نفسه.
2. في Vercel اختر المستودع.
3. اترك Framework Preset على `Other` وRoot Directory على `./`.
4. اضغط Deploy.

هذه الواجهة لا تحتوي على تسجيل حسابات حقيقي أو دفع أو بث فيديو. لا تعرض أفلامًا أو مسلسلات إلا بعد الحصول على حقوق بث مناسبة.
